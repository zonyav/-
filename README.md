# Урок 1 — введение в большие языковые модели

Готовый статический сайт-конспект. Он адаптирован для ноутбуков, планшетов и телефонов; отдельная сборка не требуется.

## Как опубликовать на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите **содержимое этой папки** в корень репозитория. Файл `index.html` должен находиться на верхнем уровне.
3. Откройте в репозитории **Settings → Pages**.
4. В блоке **Build and deployment** выберите:
   - **Source:** `Deploy from a branch`;
   - **Branch:** `main`;
   - **Folder:** `/(root)`.
5. Нажмите **Save** и дождитесь завершения публикации.

Адрес проектного сайта будет выглядеть так:

```text
https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/
```

Если репозиторий называется `ВАШ_ЛОГИН.github.io`, адрес будет короче:

```text
https://ВАШ_ЛОГИН.github.io/
```

## Как обновлять сайт

Замените `index.html` новой версией и сохраните изменения в ветке `main`. GitHub Pages автоматически опубликует обновление.

## Состав пакета

- `index.html` — весь сайт: содержание урока, оформление, переключение темы, навигация и тесты;
- `README.md` — эта инструкция (на работу сайта не влияет).

Шрифты загружаются через Google Fonts, поэтому при первом открытии сайта требуется интернет. Если сервис шрифтов недоступен, предусмотрены системные запасные шрифты — содержание и интерфейс останутся рабочими.
