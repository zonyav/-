# Внутри LLM — интерактивный курс

Статический сайт без сборки и серверной части. Он работает на компьютере и телефоне и подходит для GitHub Pages.

Внутри 57 структурированных уроков и 83 интерактивных задания: одиночный и множественный выбор, короткий ввод и смысловые сопоставления. Для видеолекций сохранены определения, примеры, практические детали и важные оговорки, а сложные места дополнительно объяснены простым языком.

Курс доводит обучение до трёх результатов: понять тему, объяснить её своими словами и собрать проект. Добавлены карта компетенций, сохраняемые письменные ответы, 18 рабочих кейсов, атлас ошибок, семь лабораторных и полноценный итоговый RAG-проект с интерфейсом, eval, логами, безопасностью и защитой по рубрике на 100 баллов. Готовые материалы находятся в папке `practice`.

Доступны светлая и тёмная темы, поиск по всему содержанию, боковое оглавление, переход к любой части, индикатор оставшегося пути и сохранение прогресса на устройстве.

## Публикация на GitHub Pages

1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите в корень репозитория всё содержимое папки `github-pages`: пять файлов сайта, `README.md` и папку `practice` целиком.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main`, папку `/ (root)` и нажмите **Save**.

Через несколько минут GitHub покажет ссылку на опубликованный сайт.

Файл `.nojekyll` этому сайту не нужен.

## Редактирование

- содержание уроков находится в `course-data.js`;
- новые практические модули и итоговый проект — в `course-extended.js`;
- дизайн и мобильная версия — в `styles.css`;
- навигация, прогресс, тема и тесты — в `app.js`.
- шаблон проекта, учебные данные и запускаемые примеры — в папке `practice`.

Прогресс сохраняется в браузере пользователя через `localStorage`; аккаунт и сервер не требуются.
