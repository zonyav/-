# Практикум курса «Внутри LLM»

Эти файлы дополняют HTML-уроки небольшими проектами. Проходите их по порядку: сначала простой классификатор, затем смысловой поиск и RAG, после этого — безопасный слой инструментов агента.

## Быстрый старт

1. Установите Python 3.10 или новее.
2. Откройте терминал в этой папке.
3. Создайте отдельное виртуальное окружение.
4. Установите зависимости из `requirements.txt`.
5. Запускайте примеры по одному.

```text
python ticket_classifier.py
python semantic_search.py
python rag_minimal.py
python agent_safe.py
```

Первый запуск файлов с эмбеддингами скачивает модель с Hugging Face и требует интернет. После загрузки модель можно использовать из локального кэша.

## Что находится в папке

- `project_brief.md` — шаблон постановки рабочей задачи и критериев качества;
- `explain_cards.md` — 12 карточек для устного объяснения ключевых идей;
- `lab_checklist.md` и `lab_report.md` — требования и отчёт для семи лабораторных;
- `error_log.csv` — журнал воспроизводимых ошибок и следующих экспериментов;
- `prompt_template.md` — каркас проверяемого промпта с безопасной обработкой входа;
- `prompt_eval.csv` — десять обычных и пограничных случаев для лаборатории промптов;
- `tickets.csv` — маленький учебный набор обращений;
- `ticket_classifier.py` — воспроизводимый TF-IDF baseline для классификации;
- `semantic_search.py` — смысловой поиск по небольшому корпусу;
- `knowledge_base.json` — демонстрационная база знаний;
- `rag_minimal.py` — retrieval, answerability gate и сборка prompt без привязки к платному API;
- `eval_cases.jsonl` — тестовые вопросы для RAG;
- `agent_safe.py` — инструменты агента, проверка аргументов и подтверждение опасного действия.
- `capstone` — полноценный итоговый RAG-проект с интерфейсом, eval и документацией.

## Как переносить в работу

Не начинайте с замены учебной модели на самую большую. Сначала замените демонстрационные данные своими обезличенными примерами, зафиксируйте baseline и критерии успеха. Меняйте по одному компоненту и каждый раз прогоняйте один и тот же набор тестов.

Для быстрой проверки retrieval и отказов выполните `python rag_minimal.py --eval`. Скрипт покажет Recall@3 и точность решения «ответить или отказаться» на примерах из `eval_cases.jsonl`.
