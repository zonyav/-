# Чек-листы семи лабораторных

## 1. Классификация

- [ ] Есть понятные классы и правило разметки.
- [ ] Train и test разделены до экспериментов.
- [ ] Построен простой TF-IDF baseline.
- [ ] Посчитаны precision, recall, F1 и confusion matrix.
- [ ] Разобраны минимум пять ошибок.

## 2. Semantic search

- [ ] У каждого документа есть стабильный id.
- [ ] Подготовлено не меньше десяти запросов с эталоном.
- [ ] Посчитан Recall@k.
- [ ] Проверены синонимы, короткие запросы и запросы без ответа.

## 3. Hugging Face

- [ ] Прочитаны model cards двух моделей.
- [ ] Проверены задача, язык, лицензия и ограничения.
- [ ] Зафиксированы точные model id и версии библиотек.
- [ ] Модели сравнивались на одинаковых примерах.

## 4. Prompting

- [ ] Есть однозначный формат результата.
- [ ] Определено поведение при отсутствии данных.
- [ ] Созданы v1, v2 и v3.
- [ ] Все версии проверены на одном eval-наборе.
- [ ] Изменялась только одна часть за эксперимент.

## 5. RAG

- [ ] Сохраняются source и chunk_id.
- [ ] Retrieval оценивается отдельно.
- [ ] Ответ содержит проверяемые ссылки.
- [ ] Есть вопросы без ответа и корректный отказ.
- [ ] Порог откалиброван на своих данных.

## 6. Agent

- [ ] Tools имеют узкие схемы аргументов.
- [ ] Права проверяет код.
- [ ] Изменения требуют подтверждения.
- [ ] Есть max steps, timeout и обработка ошибок.
- [ ] Проверяется вся траектория.

## 7. Production

- [ ] Измерены latency и стоимость.
- [ ] Определены данные, которые нельзя логировать.
- [ ] Есть ограниченный режим запуска.
- [ ] Настроены версия, мониторинг и rollback.
- [ ] Другой человек запускает проект по README.
